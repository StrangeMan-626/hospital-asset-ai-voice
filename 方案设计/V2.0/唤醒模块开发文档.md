# 唤醒模块开发文档

## 1. 文档定位

本文描述 `voice-relay`（9000 项目）中 `WS /wakeup` 唤醒检测能力的实现方案。

唤醒检测在服务端（9000）完成，使用本地 sherpa-onnx KWS 模型，不走公网 API。业务服务（9001）作为 WebSocket 客户端持续转发前端音频，9000 检测到唤醒词后返回 `wake_detected` 事件，前端本地播放固定语音回应。

## 2. 职责边界

| 模块 | 职责 |
| --- | --- |
| 前端 | 采集 PCM 音频，转发给 9001，收到 `wake_detected` 后本地播放固定回应语音 |
| 业务服务（9001） | 代理 `/ws/wakeup`，将前端音频转发至 9000 `/wakeup`，将唤醒结果回传前端 |
| voice-relay（9000） | 运行 sherpa-onnx KWS 模型，通过 `WS /wakeup` 接收音频并返回 `wake_detected` |

9000 不负责：唤醒回应语音播放、问答会话编排。

## 3. 接口协议

### 3.1 端点

```
WS /wakeup
```

### 3.2 客户端发送（Text Frame）

**建立检测会话：**

```json
{
  "type": "start",
  "terminalId": "screen-01",
  "sampleRate": 16000,
  "channels": 1,
  "wakeWord": "小万小万"
}
```

**暂停检测（保持连接）：**

```json
{ "type": "pause" }
```

**恢复检测：**

```json
{ "type": "resume" }
```

**心跳：**

```json
{ "type": "ping" }
```

### 3.3 客户端发送（Binary Frame）

PCM16/16kHz/单声道 音频分片，每帧 20～40ms。

### 3.4 服务端返回（Text Frame）

**唤醒命中：**

```json
{
  "type": "wake_detected",
  "wakeWord": "小万小万",
  "confidence": 0.95,
  "costMs": 180
}
```

**心跳响应：**

```json
{ "type": "pong" }
```

### 3.5 行为规范

1. 收到 `start` 后进入检测状态，为该连接创建独立的 sherpa-onnx stream。
2. 持续接收 Binary Frame 音频分片，送入模型检测。
3. 命中唤醒词后返回 `wake_detected`，并重置 stream（避免同一段音频重复触发）。
4. 收到 `pause` 后暂停检测，不再处理 Binary Frame（保持连接）。
5. 收到 `resume` 后恢复检测，重新创建 stream。
6. 收到 `ping` 后回复 `pong`。
7. 连接关闭后释放对应的 stream 资源。

### 3.6 并发要求

- 支持多个终端同时连接，每个终端一个 WebSocket 连接、一个独立 stream。
- 最大并发连接数：`30`。

## 4. 技术选型

- 模型：`sherpa-onnx-kws-zipformer-wenetspeech-3.3M`（中文关键词检测，仅 3.3MB）
- 运行时：Python + sherpa-onnx + FastAPI WebSocket
- 部署位置：前置机，与 voice-relay 主服务同机
- 资源占用：CPU < 5%，内存 < 100MB

## 5. 离线准备

在有公网的机器上操作：

```bash
wget https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01.tar.bz2
tar xf sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01.tar.bz2

pip download sherpa-onnx -d ./packages/
```

将模型目录和 packages 目录拷贝到前置机。

```bash
pip install --no-index --find-links=./packages/ sherpa-onnx
```

## 6. 唤醒词准备

创建原始关键词文件：

```bash
echo "小万小万 @小万小万" > keywords_raw.txt
```

转换为模型 token 格式：

```bash
sherpa-onnx-cli text2token \
  --tokens ./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01/tokens.txt \
  --tokens-type ppinyin \
  keywords_raw.txt keywords.txt
```

生成的 `keywords.txt` 放到 voice-relay 工作目录，路径通过环境变量 `WAKEUP_KEYWORDS_FILE` 配置。

## 7. 环境变量

在 `voice-relay/.env` 中增加：

```env
# --- 唤醒配置 ---
WAKEUP_ENABLED=true
WAKEUP_MODEL_DIR=./sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01

```

### 8.3 wakeup_service.py

```python
import sherpa_onnx
import numpy as np
from app.core.config import settings

def create_kws() -> sherpa_onnx.KeywordSpotter:
    model_dir = settings.WAKEUP_MODEL_DIR
    return sherpa_onnx.KeywordSpotter(
        encoder=f"{model_dir}/encoder-epoch-12-avg-2-chunk-16-left-64.onnx",
        decoder=f"{model_dir}/decoder-epoch-12-avg-2-chunk-16-left-64.onnx",
        joiner=f"{model_dir}/joiner-epoch-12-avg-2-chunk-16-left-64.onnx",
        tokens=f"{model_dir}/tokens.txt",
        keywords_file=settings.WAKEUP_KEYWORDS_FILE,
        num_threads=settings.WAKEUP_NUM_THREADS,
        keywords_threshold=settings.WAKEUP_KEYWORDS_THRESHOLD,
        keywords_score=settings.WAKEUP_KEYWORDS_SCORE,
    )

_kws: sherpa_onnx.KeywordSpotter | None = None

def get_kws() -> sherpa_onnx.KeywordSpotter:
    global _kws
    if _kws is None:
        _kws = create_kws()
    return _kws

def decode_pcm(pcm_bytes: bytes) -> np.ndarray:
    return np.frombuffer(pcm_bytes, dtype=np.int16).astype(np.float32) / 32768.0
```

### 8.4 wakeup_ws.py

```python
import asyncio
import json
import time
import logging
from fastapi import APIRouter, WebSocket, WebSocketDisconnect
from app.services.wakeup_service import get_kws, decode_pcm
from app.core.config import settings

router = APIRouter()
logger = logging.getLogger("wakeup")

_active_connections = 0
_lock = asyncio.Lock()

@router.websocket("/wakeup")
async def wakeup_ws(ws: WebSocket):
    global _active_connections
    async with _lock:
        if _active_connections >= settings.WAKEUP_MAX_CONNECTIONS:
            await ws.close(code=1008, reason="SESSION_LIMIT")
            return
        _active_connections += 1

    terminal_id = "unknown"
    kws = get_kws()
    stream = kws.create_stream()
    paused = False

    try:
        await ws.accept()
        logger.info("wakeup connection opened")
        while True:
            msg = await ws.receive()
            if "text" in msg:
                data = json.loads(msg["text"])
                msg_type = data.get("type")
                if msg_type == "start":
                    terminal_id = data.get("terminalId", "unknown")
                    stream = kws.create_stream()
                    paused = False
                    logger.info(f"[{terminal_id}] wakeup started, wakeWord={data.get('wakeWord')}")
                elif msg_type == "pause":
                    paused = True
                elif msg_type == "resume":
                    paused = False
                    stream = kws.create_stream()
                elif msg_type == "ping":
                    await ws.send_text(json.dumps({"type": "pong"}))
            elif "bytes" in msg:
                if paused:
                    continue
                samples = decode_pcm(msg["bytes"])
                stream.accept_waveform(16000, samples)
                t0 = time.monotonic()
                while kws.is_ready(stream):
                    kws.decode_stream(stream)
                result = kws.get_result(stream)
                if result:
                    cost_ms = int((time.monotonic() - t0) * 1000)
                    payload = {
                        "type": "wake_detected",
                        "wakeWord": result.strip(),
                        "confidence": 0.9,
                        "costMs": cost_ms,
                    }
                    await ws.send_text(json.dumps(payload))
                    logger.info(f"[{terminal_id}] wake_detected: {result.strip()}, costMs={cost_ms}")
                    stream = kws.create_stream()
    except WebSocketDisconnect:
        pass
    finally:
        async with _lock:
            _active_connections -= 1
        logger.info(f"[{terminal_id}] wakeup connection closed")
```

### 8.5 main.py 注册路由

在 `voice-relay/app/main.py` 中引入并注册：

```python
from app.routers.wakeup_ws import router as wakeup_ws_router

app.include_router(wakeup_ws_router)
```

## 9. 集成方式说明

voice-relay 是 Python FastAPI 项目，直接在主服务中注册 `WS /wakeup` 路由，共用 9000 端口，无需独立进程。

若 sherpa-onnx 推理阻塞 event loop（CPU 密集型），需在线程池中执行：

```python
import asyncio
loop = asyncio.get_event_loop()
await loop.run_in_executor(None, _sync_decode, stream, kws)
```

## 10. 关键参数调优

| 参数 | 说明 | 调优方向 |
| --- | --- | --- |
| `WAKEUP_KEYWORDS_THRESHOLD` | 触发阈值（0~1） | 误唤醒多 → 调大；漏检 → 调小 |
| `WAKEUP_KEYWORDS_SCORE` | 增强分数 | 值越大越容易触发目标关键词 |
| `WAKEUP_NUM_THREADS` | 推理线程数 | 单终端用 2 即可 |
